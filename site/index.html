The complete method · plain-language version

How the experiment works.

Imagine planning a fleet of research ships in a virtual ocean where the true monthly CO₂ field is already known. We can hide that truth, sample only a few places, reconstruct the rest, and check exactly how much each sampling plan missed.

01

Ask one controlled question

If every plan receives exactly 5,000 observations, does changing where they are collected change reconstruction error?

02

Create a virtual ocean

Monthly surface-ocean pCO₂, temperature and salinity from IPSL-CM6A-LR form the known “truth” for 2005, 2010 and 2014. SOCAT is used only to describe historical sampling density—not to define the truth.

03

Simulate three sampling plans

Random samples candidates equally. Historical repeats the SOCAT pattern. Coverage prioritizes sparse month–space blocks. The sample count stays fixed, so only the placement rule changes.

04

Teach one model, then hide places

The same gradient-boosting model learns from each selected sample. It then predicts places it did not see. Whole-region holdouts are the main test because they are harder than hiding scattered cells.

05

Make the comparison fair

Plans share paired random seeds, three years and five spatial folds. The default result also weights cells by spherical area and aligns both sampling and evaluation below 60°N.

06

Measure, challenge, and limit the claim

MAE, RMSE, signed bias and tail errors describe different failure modes. Sample-count, month-balance, regridding and domain checks reveal which conclusions are stable—and which still require cross-model or real-ocean validation.

Same sample count→Different locations→ Same reconstruction model→Same held-out tests→ Compare what changes
What this experiment can—and cannot—say

It tests sampling geometry under controlled model truth. It does not yet prove the best ship route, real-world cost, sea-ice accessibility, integrated carbon flux, or performance across a second reconstruction model.

What could this change in practice?

A practical next step is to compare feasible additions to ship routes or float deployments using this framework, asking which placements reduce held-out reconstruction error. That would require platform-specific measurements, access and cost constraints, and another reconstruction model before making deployment recommendations.
